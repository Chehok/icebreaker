🍜 먹는 것 & 취향 '이 중 누가?' 질문 29개

반찬, 라면, 간식 먹는 습관으로 어울리는 사람을 가리키는 질문이에요. 식사 자리에서 바로 써먹기 좋아요.

진행 팁 — 같이 밥을 먹는 중이라면 실제 먹는 모습을 근거로 가리켜 보세요.

😋 순한맛 16개 처음 만난 사이에도 편한 질문

  1. 이 중에 밥 먹을 때 반찬을 한쪽에 모아 둘 것 같은 사람은?
  2. 이 중에 라면에 넣을 재료를 냉장고에서 한가득 꺼낼 것 같은 사람은?
  3. 이 중에 과자 봉지를 뜯으면 그릇에 덜어 먹을 것 같은 사람은?
  4. 이 중에 김밥에서 싫어하는 재료를 꼭 빼 먹을 것 같은 사람은?
  5. 이 중에 빵집에 들어서면 빵 냄새부터 맡을 것 같은 사람은?
  6. 이 중에 쌈을 너무 크게 싸서 한입에 못 넣을 것 같은 사람은?
  7. 이 중에 배달 음식이 도착하면 그릇에 예쁘게 옮겨 담을 것 같은 사람은?
  8. 이 중에 고깃집에서 집게를 좀처럼 놓지 않을 것 같은 사람은?
  9. 이 중에 식당 반찬만으로도 밥 한 공기를 먹을 것 같은 사람은?
  10. 이 중에 과일은 껍질째 먹는 걸 좋아할 것 같은 사람은?
  11. 이 중에 식사 중에 물을 몇 번씩 따라 마실 것 같은 사람은?
  12. 이 중에 소스 두 가지를 섞어 자기만의 배합을 만들 것 같은 사람은?
  13. 이 중에 튀김은 눅눅해지기 전에 서둘러 먹을 것 같은 사람은?
  14. 이 중에 냉동만두를 늘 냉동실에 채워 둘 것 같은 사람은?
  15. 이 중에 떡집 앞에서 발걸음을 멈출 것 같은 사람은?
  16. 이 중에 카레를 끓일 때 며칠 치를 한꺼번에 만들 것 같은 사람은?

🌶️ 매운맛 13개 조금 친해졌다면 솔직하게

  1. 이 중에 식사 속도가 느리다는 말을 들으면 괜히 빨리 먹을 것 같은 사람은?
  2. 이 중에 고수가 싫다고 말하기 민망해서 몰래 골라낼 것 같은 사람은?
  3. 이 중에 자기 레시피에 조언을 받으면 자존심 상할 것 같은 사람은?
  4. 이 중에 안 맵다고 큰소리치며 땀을 닦을 것 같은 사람은?
  5. 이 중에 같이 먹는 감자튀김에서 긴 것만 고를 것 같은 사람은?
  6. 이 중에 추가 반찬을 부탁하는 일은 친구에게 미룰 것 같은 사람은?
  7. 이 중에 요리하기 귀찮아서 손님 초대를 취소하고 싶을 것 같은 사람은?
  8. 이 중에 같이 요리한 뒤 설거지만 슬쩍 피할 것 같은 사람은?
  9. 이 중에 음식을 남기면 눈치 보여 억지로 다 먹을 것 같은 사람은?
  10. 이 중에 자기 요리를 칭찬받으려고 감상을 계속 물을 것 같은 사람은?
  11. 이 중에 커피 취향을 놀림받을까 봐 달달한 메뉴를 못 시킬 것 같은 사람은?
  12. 이 중에 무료 후식을 더 달라고 했다가 민망해질 것 같은 사람은?
  13. 이 중에 자기 몫의 배달비를 아끼려고 남의 주문에 낄 것 같은 사람은?

🎯 이 중 누가? 이렇게 진행해요

  1. 질문을 읽고 '하나, 둘, 셋!'에 맞춰 가장 잘 어울리는 사람을 동시에 가리켜요.
  2. 가장 많이 지목된 사람은 '인정' 또는 '억울'을 외치고 한마디 해명할 기회를 가져요.
  3. 가리킨 사람에게 왜 그렇게 생각했는지 물어보면 의외의 칭찬이 나오기도 해요.
  4. 지목받고 싶지 않은 사람은 처음부터 빠져도 되고, 놀림이 될 것 같은 질문은 바로 넘겨요.
