# 🧊 Icebreaker

모임에서 어색함을 깨기 위한 **대화 주제 랜덤 뽑기 + 밸런스 게임 + 이 중 누가?** 웹앱입니다.
`index.html` 파일 하나로 동작하며, 빌드 과정이나 외부 의존성이 없습니다.

👉 **바로 사용하기:** https://chehok.github.io/icebreaker/

## 주요 기능

- **💬 대화 주제 모드** — 23개 카테고리, 총 416개 질문 중 하나를 랜덤으로 뽑습니다.
- **⚖️ 밸런스 게임 모드** — 10개 카테고리, 총 216개의 A/B 양자택일 질문을 뽑습니다.
- **🎯 이 중 누가? 모드** — 6개 카테고리, 총 108개 질문(순한맛 60 + 매운맛 48)으로 함께할 사람을 가리키는 게임입니다.
- **📱 PWA** — HTTPS에서 홈 화면에 설치할 수 있으며, 최초 온라인 로딩과 서비스 워커 설치가 끝난 뒤 오프라인으로 사용할 수 있습니다.
- **😋 순한맛 / 🌶️ 매운맛** 난이도 선택과 카테고리 필터를 지원합니다.
- 세 모드 합계 **740개**: 대화 주제 416개(230/186), 밸런스 216개(118/98), 이 중 누가? 108개(60/48). 괄호는 순한맛/매운맛입니다.
- 답하기 곤란한 질문은 건너뛰고, 이 중 누가?는 참여하고 싶은 사람끼리 진행하세요.
- 마지막으로 사용한 모드는 브라우저(`localStorage`)에 저장되어 다음 방문 때 그대로 열립니다.

## 로컬에서 실행하기

별도 설치가 필요 없습니다. 저장소를 받은 뒤 `index.html`을 브라우저로 열면 됩니다.

```powershell
git clone https://github.com/Chehok/icebreaker.git
cd icebreaker
start index.html
```

PWA 설치·오프라인은 GitHub Pages 또는 로컬 HTTP 서버에서 확인하세요. `file://`로 열면 질문 뽑기는 동작하지만 서비스 워커는 등록하지 않습니다. Pretendard 글꼴은 jsDelivr CDN에서 받아 서비스 워커의 글꼴 캐시(`icebreaker-fonts-v1`)에 저장하며, 받지 못하면 시스템 글꼴로 표시됩니다.

## 질문 추가하기 (요약)

질문 데이터는 모두 `index.html` 안의 `<script>`에 있습니다.

- 대화 주제: `mildQuestions`(순한맛) / `spicyQuestions`(매운맛) 배열에 `{ text: "...", category: "카테고리키" }` 추가
- 밸런스 게임: `balanceItems` 배열에 `{ a: "...", b: "...", category: "카테고리키", spice: "mild" 또는 "spicy" }` 추가

- 이 중 누가?: `whoItems` 배열에 `{ text: "...", category: "카테고리키", spice: "mild" 또는 "spicy" }` 추가

자세한 절차, 예시, 테스트 체크리스트는 [AGENTS.md](./AGENTS.md)를 참고하세요.

## 배포

GitHub Pages가 `main` 브랜치 루트를 그대로 서비스합니다.
앱이나 캐시 파일을 수정하면 `sw.js`의 캐시 이름도 올려 주세요(현재 `icebreaker-v5`). 새 페이지는 온라인 방문 시 네트워크에서 우선 읽고, 통신 실패 시 캐시를 사용합니다.

`index.html` 수정 → `main`에 커밋 & 푸시 → 보통 1~2분 안에 자동 반영됩니다. (자세한 내용은 [AGENTS.md](./AGENTS.md))
